# FFmpeg internals reference

The explorer uses FFmpeg 9.0.2 (`n9.0.2`), the release listed on FFmpeg's download page when the reference was researched on November 18, 2026. The learning app has no native FFmpeg dependency or earlier version pin. Field declarations and comments come from the release source archive. The release uses libavformat 63, libavcodec 63 and libavutil 61. [FFmpeg downloads](https://ffmpeg.org/download.html) · [Tagged source](https://github.com/FFmpeg/FFmpeg/tree/n9.0.2) · [libavformat version](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavformat/version_major.h#L32) · [libavcodec version](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavcodec/version_major.h#L28) · [libavutil version](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/version.h#L81)

## Public declarations

| Type | Role and connections | Source |
| --- | --- | --- |
| `AVFormatContext` | Demuxing or muxing session. Counted pointer arrays reference streams, groups, chapters and programs. Other typed pointers include I/O, format descriptors, codec descriptors and options metadata. | [avformat.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavformat/avformat.h#L1316) |
| `AVStream` | One elementary stream. Contains stream timing, a pointer to codec parameters and an embedded `AVPacket` for an attached picture. A stream group can reference the same streams. | [avformat.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavformat/avformat.h#L749) |
| `AVCodecParameters` | Encoded-stream description, including codec setup bytes, counted coded side data, video properties and an embedded audio channel layout. `avcodec_parameters_to_context()` copies corresponding properties into a working codec context. | [codec_par.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavcodec/codec_par.h#L49) · [avcodec.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavcodec/avcodec.h#L2160) |
| `AVPacket` | Encoded payload, stream index, timing and optional side data. `buf` may own the payload through a reference; packet side data has separate ownership. | [packet.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavcodec/packet.h#L550) |
| `AVFrame` | Raw picture or audio samples. Plane pointers, strides, buffer references and side data accompany the decoded values. A video plane can start inside the buffer and use a negative stride. Planar audio with more than eight planes uses `extended_data`. | [frame.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/frame.h#L428) |

Follow a typed data pointer or embedded record to its public declaration. Preserve the distinction between a counted array of records (`AVPacket.side_data`), a counted array of pointers (`AVFrame.side_data`), and a fixed array (`AVFrame.data[AV_NUM_DATA_POINTERS]`). Preserve union members and discriminators, such as `AVStreamGroup.type` for `params` and `AVChannelLayout.order` for `u.mask` or `u.map`. Shared targets use the same definition. Callback signatures represent executable hooks. Byte buffers and `void *` fields end at their declared type, with payload interpretation supplied by documentation where relevant. [packet.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavcodec/packet.h#L580) · [frame.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/frame.h#L466) · [AVStreamGroup](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavformat/avformat.h#L1142) · [channel_layout.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/channel_layout.h#L319)

`AVDictionary`, `AVBuffer` and `AVCodecTag` are opaque at the public header boundary. Use dictionary accessors to get or iterate metadata entries. `AVBufferRef` exposes `buffer`, `data` and `size` and uses `av_buffer_ref()` and `av_buffer_unref()` for reference management. `AVProgram` declares private fields after `pmt_version`, and the release still declares the deprecated `AVStreamGroupLCEVC` alias. Use the library allocators and matching headers when working with these objects in C. [dict.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/dict.h#L90) · [buffer.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/buffer.h#L74) · [AVCodecTag](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavformat/avformat.h#L447) · [AVProgram](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavformat/avformat.h#L1240) · [LCEVC alias](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavformat/avformat.h#L1076)

## Display matrix

- Stream metadata lives in `stream->codecpar->coded_side_data`. Look up `AV_PKT_DATA_DISPLAYMATRIX` with `av_packet_side_data_get()` and give it `nb_coded_side_data`. For an individual packet use `av_packet_get_side_data()` with the same enum. For a decoded frame use `av_frame_get_side_data()` with `AV_FRAME_DATA_DISPLAYMATRIX`. Each lookup can be absent. Older examples use the former `AVStream.side_data` or `av_stream_get_side_data()` API. [codec_par.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavcodec/codec_par.h#L73) · [Packet API](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavcodec/packet.h#L468) · [Packet lookup](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavcodec/packet.h#L805) · [Frame lookup](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/frame.h#L1013) · [API history](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/doc/APIchanges#L724)
- Check for at least nine `int32_t` entries before reading. The native-endian layout is `a, b, u, c, d, v, x, y, w`. Entries use 16.16 fixed point except `u`, `v` and `w`, which use 2.30. The matrix describes presentation and can include translation, scale or reflection. [display.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/display.h#L30) · [ffprobe size check](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/fftools/ffprobe.c#L1106)
- `av_display_rotation_get()` extracts a counterclockwise angle in degrees and documents `NaN` for a singular matrix. `av_display_rotation_set()` overwrites the matrix with a pure clockwise rotation. `av_display_matrix_flip()` modifies the matrix in place. Preserve the full matrix when the transformation includes other components. [display.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/display.h#L73)

## Time bases

- An `AVRational` time base is seconds per tick. Convert a known timestamp for display with `ticks * av_q2d(tb)`. For example, `45,000` ticks at `1/90,000` represents 0.5 seconds. `AVStream.avg_frame_rate` describes frames per second. Container `AVFormatContext.start_time` and `duration` use `AV_TIME_BASE_Q` (`1/1,000,000` seconds), while their `AVStream` counterparts and packets from `av_read_frame()` use the stream's time base. [rational.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/rational.h#L58) · [Demuxed packet timing](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavformat/avformat.h#L161) · [Container timing](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavformat/avformat.h#L1435) · [AV_TIME_BASE](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/avutil.h#L243)
- Use `av_rescale_q(ts, source_tb, target_tb)` for integer time-base conversion and `av_rescale_q_rnd()` for explicit rounding. Check `AV_NOPTS_VALUE` or pass `AV_ROUND_PASS_MINMAX` with a rounding mode before converting timestamps. `av_packet_rescale_ts()` converts known PTS and DTS and any positive duration. Its implementation leaves the packet's `time_base` field untouched. [mathematics.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/mathematics.h#L123) · [packet.c](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavcodec/packet.c#L538)
- Determine the source time base from the producer's contract. In this release, the `AVPacket.time_base` and `AVFrame.time_base` comments describe limited use at decoder, encoder, muxer and filter boundaries. Set `AVCodecContext.pkt_timebase` from the incoming packet time base when configuring a decoder. For muxing, use the output stream time base after `avformat_write_header()` since the muxer can change it. [Packet time base](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavcodec/packet.h#L641) · [Frame time base](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/frame.h#L577) · [Codec context time bases](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavcodec/avcodec.h#L533) · [Stream time base](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavformat/avformat.h#L779)

Older examples can name fields missing in this release. Use `AVFrame.duration` for frame duration, `ch_layout` for audio channel layout, `AV_FRAME_FLAG_KEY` in `AVFrame.flags` for a frame's keyframe flag and `AV_PKT_FLAG_KEY` in `AVPacket.flags` for a packet's flag. [frame.h](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/frame.h#L637) · [Frame duration and channel layout](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavutil/frame.h#L804) · [Packet flags](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/libavcodec/packet.h#L650) · [API history](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/doc/APIchanges#L1012)

## Verify the shipped inventory

Extract the [official source archive](https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz) and run the checks from the repository root.

```sh
python3 scripts/ffmpeg-inventory.py /path/to/ffmpeg-9.0.2 --check
node --experimental-strip-types --test tests/ffmpegInternals.test.mjs
```

The first check compares names, declaration order, C types, and constants with the release headers. The second checks explanation coverage, cross-references, concept searches, and signed 64-bit timestamp input. The tagged source links in the explorer identify the exact patch release. Its Doxygen links give the API documentation for the 9.0 series.
